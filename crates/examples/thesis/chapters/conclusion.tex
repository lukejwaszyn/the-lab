\chapter{Conclusion}
\label{chap:conclusion}

Reusing engine state turns a rebuild from a function of document length into
a function of edit position. The approach works for documents that behave
deterministically and falls back to a full run otherwise
(Section~\ref{sec:limitations}).

\section{Future Work}
\label{sec:future-work}

Two directions follow from the results in Section~\ref{sec:results}: finer
snapshots inside long pages, and reuse across changes to auxiliary files.
